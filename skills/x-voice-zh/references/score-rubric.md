# 评分口径（与 `score_draft.py` 一致）

- 起始 100 分；每个硬禁项 −20；每个软项 −6；最低 0。
- 同一规则在一条草稿里只记一次（除了 H12，每个禁用词记一次）。
- 空位（`__`、`＿＿`、`【待补…】`）不扣分，但 `ready_to_post` 为 false。空位里的内容不参与规则检查。
- 结论：
  - 有硬禁项 → 「重写」
  - 没有硬禁项，但有空位 → 「补完空位再发」
  - 只有软项 → 「基本可发」
  - 都没有 → 「可发」
- **分数只说明「像不像模板腔」，不说明内容好不好、会不会火。** 80 分的帖子也可能没人看；真正的好坏要看发出去后的收藏和回复。
- 上限（S05）默认 5 行 / 160 字；给了 `--profile` 就按你的 90 分位推算。
- 加 `--json` 可以拿结构化结果，`--fail-on-hard` 可以在脚本里当检查用。
