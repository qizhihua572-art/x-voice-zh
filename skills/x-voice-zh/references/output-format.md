# 输出格式

一次最多 5 条，**首推排最前**。没有对得上用户事实的爆款，就老实说「今天没有能转的」，别硬凑。

每条这样写：

```
### N. （一句话标题）
- 原帖：链接；浏览 / 回复 / 收藏（真实数字，别人转述的写「作者说」）
- 为什么火：一句话，要有依据（钩子类型 + 读者能拿走什么）
- 转写草稿：
  （2–4 行，空位用 __）
- 打分：xx/100，硬禁 0，软项：…
- 怎么发：引用原帖还是单独发；配什么图/视频；链接放评论区；先做完什么
- 要补的空：__ 是 …（只有你知道）
```

不转的爆款，一行说明：`不转：原因（比如你还没有对应的成品）`。

最后一句提醒：草稿都没发，发不发、什么时候发由你定。
