# 真实事实清单模板（防编造的核心）

这份清单只由**用户本人**确认。AI 转写时只准用这里写了的事实；清单里没有的，一律在草稿里留空位 `__`。

```
## 我在做什么
- （项目、做了多久、一个人还是团队）
## 我的数字（只写能拿出证据的）
- （访问、注册、付费、收入、成本……带日期）
## 我用的工具和花的钱
-
## 我的成品 / 可以演示的东西
-
## 我踩过的坑（真的发生过的）
-
## 我不想写进帖子的东西（禁用词也放这里）
-
```

## 规则
- 每条一句话，带日期更好。
- 不确定的写「不确定」，转写时那条就当不存在。
- 别人的数字不要放进来；要引用别人，在草稿里写「作者说」。
