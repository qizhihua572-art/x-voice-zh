# 中文去 AI 味规则（`score_draft.py` 实现的就是这一份）

原则：去 AI 味不是换同义词，是删掉空话、换成真事。**宁可留一点 AI 味，也不造假事实。**
这些规则是对常见中文 AI 腔写法的总结，用我们自己的话写；署名和参考见 `NOTICE.md`。

## 硬禁（命中一个就重写，每个扣 20 分）
| ID | 规则 | 例子 |
|---|---|---|
| H01 | 翻案腔：不是…而是 / 并非…而是 / 与其说…不如说 / 表面…实际 / 你以为…其实 | 不是工具的问题，而是你没想清楚 |
| H02 | 金句或升维收尾：本质上 / 归根结底 / 说到底 / 才是真正的 | 本质上，作品才是壁垒 |
| H03 | 硬凑互动的结尾提问：你怎么看 / 评论区聊聊 / 你站哪边 | 你怎么看？ |
| H04 | 标题党钩子：90%的人都不知道 / 停止… / 震惊 / 重磅 | 99%的人都不知道 |
| H05 | 三连排比：连续三行同一个开头 | 他会…他会…他会… |
| H06 | 口头禅起手：说白了 / 说穿了 / 先说结论 / 一句话总结 | 说白了，就是… |
| H07 | 提示语冒号：核心是： / 关键在于： / 总结： | 核心是：先收钱 |
| H08 | 铺垫和客服腔：让我们 / 好问题 / 拭目以待 / 综上所述 | 让我们拭目以待 |
| H09 | emoji 当项目符号：两行以上以表情开头 | ✅省钱 ✅省时间 |
| H10 | 感叹号连发（3 个连着，或全文 5 个以上） | 太强了！！！ |
| H11 | 虚构人物故事：我有个朋友… | 我有个朋友做了… |
| H12 | 命中你自己设的禁用词（`--ban-words`） | — |

## 软项（只提示，每个扣 6 分，别硬改）
S01 句首路标词；S02 顿号罗列过密；S03 概括词盖住数字；S04 破折号当悬念；S05 太长；S06 链接在正文；
S07 数字不在事实清单里；S08 「不是 A，是 B」；S09 话题标签 >2；S10 求收藏；S11 三点清单式；S12 和语气画像不一致。

## 别误改（实测人写的文章里一样常见，不要当 AI 味去改）
- 问句和设问本身（只有「硬凑」的才是问题）
- 句长参差（别为了像人故意拆碎）
- 「首先/其次」
- 单个「漂亮词」（赋能、闭环等）——只有词堆在一起、没有信息时才是问题
- 排比本身（只有连续三句同骨架才动）
- 比喻、emoji 本身（你的画像里常用就保留）

## 打分器看不出来的（需要 AI 和你判断）
- 万能话：换个账号换个话题也成立的句子
- 复述原帖：只是把别人的观点换个说法
- 事实是不是真的——这个只有你知道，所以才要空位和事实清单
