# 示例输出（全部虚构）

> 这是用 `examples/` 里的虚构数据跑出来的一次完整输出：作者 `demo_maker` 和三个大号 `demo_big_a/b/c` 都不是真实账号，数字也是编的，只用来演示格式。
> 草稿里的 `__` 是「只有本人知道、事实清单里没有」的空位，AI 不许替他编。

### 1. 把「上线 N 天、付费 N 个」转成自己的进度（首推）
- 原帖（示例）：https://example.com/demo/b1；浏览 74000 / 回复 96 / 收藏 540
- 为什么火：钩子是「报数字」，一句话讲清多久做到什么，后面一句交代做法，把可存的细节放到评论区。
- 转写草稿：
```draft
好家伙，我的记账小工具上线 12 天了🤣
访问 120，注册 9，付费 0😂
第一次收到的 5 刀，还是朋友给的🥲
```
- 打分：100/100，硬禁 0
- 怎么发：单独发，配一张后台数据截图（先打码），不放链接。评论区补一句做法。
- 要补的空：无（数字都在事实清单里）。如果想写「做了 __ 个功能」，先补上。

### 2. 把「坦白：3 个月 0 付费」转成自己的定价困惑
- 原帖（示例）：https://example.com/demo/b2；浏览 52000 / 回复 140 / 收藏 210
- 为什么火：钩子是「坦白」，先认一个失败，读者容易代入，也容易有话说。
- 转写草稿：
```draft
救命，我把价格从 9 刀改成 5 刀🥲
注册一个都没多😂
你们的小工具，第一个付费用户是怎么来的？
```
- 打分：100/100，硬禁 0
- 怎么发：单独发；问题放最后，只问一个。
- 要补的空：无。

### 3. 把「免费模板」转成上线前检查清单（给收藏用）
- 原帖（示例）：https://example.com/demo/b3；浏览 61000 / 回复 40 / 收藏 880
- 为什么火：标题就说了读者能拿走什么（可复用的模板），完整版放评论区。
- 转写草稿：
```draft
上线前的检查，都是我踩出来的🤣
第一条，价格有没有少打小数点
第二条，手机上能不能点到按钮😂
第三条，通知邮件会不会进垃圾箱
完整版放评论区，还有 __ 条我晚点补🥲
```
- 打分：硬禁 0，有 1 个空位没补
- 怎么发：先把评论区的完整清单写好再发正文。
- 要补的空：清单还有几条，由本人决定。

### 不转
- 「做小工具最贵的不是服务器…」：这是一个需要亲身验证的判断，事实清单里没有「删掉功能后留存变化」的数据，不转。
- 「卡了三天：支付回调丢」：事实清单里没有支付相关经历，不转。

提醒：草稿都没发，发不发、什么时候发由你定。
